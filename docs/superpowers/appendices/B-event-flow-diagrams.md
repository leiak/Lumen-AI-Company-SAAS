### 异常分支

1. **审批驳回**：流程状态回到发起人，可修改后重新提交

3. **账号创建失败**：事务回滚（Seata AT），手动重试
4. **MQ 发送失败**：本地消息表兜底，定时扫描重发

| `GET /auth/user/profile` | 新员工 | 登录后查看自己档案 |

3. **个税累计错误**：支持手动调整后重算

### 关联接口

- `POST /pay/calc/run`
- `GET /pay/slip/{period}/list`
- `POST /pay/bank-file/generate`

## B.10 关键设计原则

1. **所有跨服务调用走事件**，不直接 RPC（除基础设施类）
2. **事件 payload 必须包含**：`tenantId`、`traceId`、`bizKey`、业务字段
3. **消费者幂等**：DB 唯一索引 + Redis 去重
4. **失败重试**：3 次本地重试 + 死信队列
5. **顺序保证**：同一业务单据用相同 partition key
6. **可观测**：事件 trace 可在 SkyWalking 串联
